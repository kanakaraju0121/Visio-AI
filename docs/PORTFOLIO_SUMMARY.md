# Portfolio summary

**Visio-AI — Voice-Controlled Raspberry Pi Vision Robot**

A Raspberry Pi robotics prototype integrating a two-motor L298N drive stage, voice-command input, camera capture, YOLO-based object detection, browser video streaming and optional Groq conversational responses.

**Engineering areas represented in the repository:** Python, Raspberry Pi, RPi.GPIO, PWM motor control, L298N, OpenCV, Picamera2, Ultralytics YOLO, Flask, SpeechRecognition, Linux audio tools and API integration.

**Award context:** The project was presented by the team at Protospark during E-MANTHANA 2025; the supplied certificate records first place. The award is a team achievement and should be attributed to the team in public descriptions.

**Evidence available in this repository:** robot hardware photographs and source files. Add a genuine demo video, wiring diagram, setup-tested logs and measured performance only after capturing and validating them.
